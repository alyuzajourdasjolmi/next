🗄️ Database Schema

Table: user_addresses

id BIGINT (PK) user_phone TEXT label TEXT recipient_name TEXT recipient_phone TEXT full_address TEXT detail_address TEXT latitude DECIMAL(10,8) longitude DECIMAL(11,8) maps_link TEXT is_primary BOOLEAN created_at TIMESTAMPTZ updated_at TIMESTAMPTZ

Triggers

  • ⚡ Auto Update Timestamp - Update updated_at saat record diupdate
  • ⚡ Ensure Single Primary - Hanya 1 alamat primary per user

⚛️ Komponen React

1. AddressManager

Komponen lengkap untuk CRUD alamat

<AddressManager userPhone="6285263965031" mode="manage" onSelectAddress={(addr) => { console.log(addr); }} />

2. AddressSelector

Modal untuk pilih alamat saat checkout

<AddressSelector userPhone={userPhone} onSelect={(addr) => handleSelect(addr)} onClose={() => setShowModal(false)} onAddNew={() => router.push('/addresses')} />
